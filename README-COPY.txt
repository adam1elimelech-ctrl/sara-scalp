איך להעלות — חשוב לקרוא

הבעיה עכשיו: קבצי האנגלית (מתיקיית en) הועתקו לשורש האתר.
לכן gallery.html ו-index.html באנגלית, והעיצוב נשבר
(הדפדפן מחפש CSS בכתובת הלא נכונה).

מה לעשות בגיטהאב:

1. פרקו את הזיפ.
2. היכנסו לתיקייה sara-restore (לא ל-en).
3. העתיקו לשורש הריפו sara-scalp:
   - את כל קבצי ה-html שכאן (index.html, gallery.html וכו')
   - את התיקייה assets
   - את התיקייה en בשלמותה (תיקייה, לא את הקבצים מתוכה לשורש)

אסור:
- להעתיק את הקבצים מתוך en לשורש
- למחוק את assets
